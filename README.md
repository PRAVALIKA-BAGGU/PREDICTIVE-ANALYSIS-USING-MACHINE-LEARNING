# Student Performance Preediction Using Machiine Learning

## Prediction Overview
This project predicts student math scores using machine learning techniques based on demographic and academic performance data. This project includes data processing, visualization, feature engineering, model training, evaluation, and prediction using multiple regression algorithms.

## Features
- Data preprocessing and feature encoding
- Correlation analysis and visualization
- Multiple regression model comparison
- Feature importance analysis
- Model saving and loading using Pickle
- Prediction on new student data

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Pickle

## Machine Learning Workflow
1. Data Collection
2. Data Exploration
3. Data Preprocessing
4. Feature Selection
5. Train-Test Split
6. Model Training
7. Model Evaluation
8. Feature Importance Analysis
9. Model Saving and Prediction

## Models Used
- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor

## Model Performance
- Linear Regression R² Score: 0.88
- Decision Tree R² Score: 0.71
- Random Forest R² Score: 0.85

Linear Regression achieved the best prediction performance for this dataset.
